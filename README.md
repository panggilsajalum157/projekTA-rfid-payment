# projekTA-rfid-payment

## Sistem Pembayaran Santri Berbasis RFID

Project ini merupakan aplikasi pembayaran santri menggunakan kartu RFID yang terintegrasi dengan ESP32 dan PHP Native.

---

## Fitur

- Login Admin
- Data Santri
- Top Up Saldo
- Pembayaran RFID
- Riwayat Transaksi
- Cetak Struk
- Laporan Transaksi
- Monitoring UID RFID

---

## Teknologi

- PHP Native
- MySQL
- HTML
- CSS
- JavaScript
- ESP32
- RFID RC522

---

## Struktur Folder

```
projekTA/
│
├── api/
├── assets/
├── sketch/
└── web/
```

---

## Cara Menjalankan

1. Import database MySQL.
2. Salin folder `projekTA` ke `htdocs`.
3. Jalankan Apache dan MySQL menggunakan XAMPP.
4. Akses:

```
http://localhost/projekTA/web
```

5. Upload program ESP32 melalui Arduino IDE.
6. Hubungkan modul RFID RC522.
